IPHONE

Apple Reminders setup

This is a one-time iPhone setup. Apple does not let a normal website directly create a Reminders task with an alert.

  1. Open Shortcuts and create a shortcut named Nikki Reminder.
  2. Have it accept text input containing JSON.
  3. Read the JSON values title, notes, due_date, and due_time.
  4. Use the Reminders action to add a reminder with that title, notes, and due date/time.

After that, the iPhone Reminder button in Operations sends each saved reminder straight to that shortcut.
